— 02

AI 指挥力

驱动人机协同，并将个人经验与业务逻辑 Agent 化的能力。基于你提报到 AI 案例库的实践案例评估。

— 考察维度 · 4 层递进

从"用 AI"到"管 AI"的能力梯度。每一档需具备前置档位的全部能力，逐级递进、不可跳过。

D1AI 基础素养 基础门槛 · AI 加速 能与 AI 工具有效协作完成日常任务。能写出结构清晰、目的明确的 Prompt；能主动调用多元 AI 工具（不局限于一个平台）完成翻译、总结、起草、查询、分析等任务；对 AI 边界有清醒认知。
D2人机协同分工 关键能力 · AI 协同 能在真实业务场景中识别 AI 的切入点，设计合理的人机分工模式（什么交给 AI、什么留给人）。能根据任务复杂度选择合适的协同模式，并为 AI 出错或边界外情况设计人工介入路径。
D3Agent 接管能力 进阶能力 · AI 接管 能将一个完整业务环节交给 AI 独立完成。交付的工作流 / 智能体实现端到端闭环（输入→处理→输出→反馈），无需逐步推进；具备异常处理机制（错误捕获、降级、人工接管），月运行次数与成功率经得起检验。
D4范式创造能力 顶级能力 · AI 重塑 通过 AI 让原本不可能或不存在的工作方式成为现实。带来结构性的工作方式变化（不只是更快/更便宜，而是创造了新的工作形态），对所在岗位/团队/业务线产生可被推广的范式价值。
— 怎么打分

两段式评级：先定档位决定落在哪个区间，再根据精算确定具体得分。取你最高分案例为最终得分。

阶段一 档位定位 · 决定区间

案例的 深度 D（AI 扮演什么角色）× 价值 V（业务交付实际反馈）双维度查表评估区间。

深度 D \ 价值 V V1 · 有价值有优化空间 V2 · 质量效率明显改善 V3 · 完全成型 · 团队日常

D2 · 人机协同分工设计合理的人机分工模式 17–2020–2323–26
D3 · Agent 接管能力AI 独立完成完整工作环节 26–2929–3232–35
D4 · 范式创造能力AI 让不可能成为可能 32–3535–3837–40
— V 维度 · 价值评级三档
V1 有价值 · 有优化空间
个人能跑，有业务价值，但仍有较大优化空间。
V2 质量效率明显改善
个人能跑，有业务价值，且因 AI 产出的工作质量和效率均有较明显改善。
V3 完全成型 · 团队日常
有业务价值，完全成型，已纳入团队其他成员的日常工作流程或内容，带来较显著的团队效率提升。

— 评判机制 · AI 主导 · 人在关键节点把关

每个维度由谁评判是这套体系的核心设计 — Agent 处理标准化判别（D、Q），上级处理需要业务上下文的价值判断（V），各司其职。

D 深度
100% Agent 评判
基于员工提报的事实描述（AI 承担的环节 + 闭环判别问题 + 范式判别问题），Agent 按标准化规则判定 D 等级。员工无需自评。
⚙ Agent
V 价值
Agent 推荐档位 + 上级人工确认
Agent 基于提报内容初步推荐 V 等级，上级在管理端核实业务上下文——案例是否真在解决实际问题、价值是否真实而非"伪价值"。这是整套机制最关键的人在环节。
⚙ Agent + 人 直属上级
Q 工程质量
100% Agent 评判
基于员工对错误处理机制的描述与证据，Agent 按"完整 / 部分 / 缺失"三档客观打分。这是技术属性，无需人工介入。
⚙ Agent
— D4 评审委员会兜底
D4 是顶级档位，需评审委员会基于"3 条硬标准"集中评议（① 10× 跃迁 / ② 能力扩展 / ③ KPI 重写）。员工需提交完整证据材料，由 HR、业务负责人组成的评审委员会做资格审定。
— 真实案例 · 每档一个供你参考
D1 · AI 基础素养
市场推文多语言翻译与本地化 Prompt 包 — 市场营销岗
场景：一名市场专员针对小红书、Instagram、LinkedIn 三个不同平台，整理出 3 套结构化翻译 Prompt 模板，能保留中文原意的同时贴合每个平台的语言风格，单篇推文翻译时间从 40 分钟降至 10 分钟。
为什么是 D1：AI 是工具，员工仍是工作主体。Prompt 输出后仍需员工根据当下营销节点、品牌口吻做最后润色才能发布。
D2 · 人机协同分工
新品推广活动方案生成器 — 市场活动策划岗
场景：一名市场活动策划设计了一套人机协同流程：输入新品信息与目标用户 → AI 自动生成活动方案初稿，包括活动形式、宣传渠道和关键节点 → 另一款 AI 对方案进行评估并给出优化建议 → 策划在活动前结合团队反馈和品牌调性进行最终确认与个性化调整。5 位策划在使用，月覆盖 50+ 个线上活动策划方案。
为什么是 D2：AI 承担了"方案起草和优化"这一独立环节，策划只做最终决策。但每次活动仍需策划主动触发并定稿，不是端到端闭环。
D3 · Agent 接管能力
标准合同自动审查 Agent — 法务岗
场景：一名公司法务搭建了端到端合同审查 Agent:合同上传 → AI 自动识别合同类型、抽取关键条款(付款、违约、知识产权)、对比公司模板、标注风险点位置与等级 → 输出审查报告。律师只看异常合同的异常段落。系统月稳定处理 800+ 份标准合同,准确率 95%,疑难合同自动转人工。
为什么是 D3：AI 独立完成了"合同初审"这一完整业务环节,从输入到输出端到端闭环。律师不主动介入,工作流也能完成;律师只做监督与异常处理。
D4 · 范式创造能力
全球行业雷达系统 — 战略岗
场景：原本战略团队每季度只能深度研究 3 个赛道(人力天花板)。员工搭建了"行业雷达系统"——12 个 Agent 协同持续追踪全球 500+ 公司的公开信息、专利、招聘动态、产品发布,自动生成赛道动态周报。战略分析师从"信息收集"转为"信号判读"。
为什么是 D4(满足 3 条硬标准):
① 数量级跃迁:单季度可深度覆盖赛道数从 3 个 → 50+ 个(>10×)
② 能力扩展:原本无法做到的"实时全球追踪"成为可能
③ KPI 重写:战略团队 KPI 从"产出研报数量" → "战略预警准确率 + 决策影响力"

学习进化力

本职领域学习速度本岗位职责范围内学习新工具、新方法、新流程的速度 vs 团队平均

— 04

价值创造力

— 考察维度
本职职责的扎实交付在本岗位范围内，稳定、高质量地交付工作

不设限的担当面对超出当前职责或经验的挑战性任务，不设限，能主动顶上、拿到结果，并对最终结果负全责
交付韧性在面临不确定因素时，能够调动资源、跨部门协同以确保结果达成的程度
业务增值贡献推动可量化的业务增长 / 降本 / 突破；岗位特性导致较少接触业务增量的，可量化的效率提升、质量提升、风险降低同等计入

5错误处理机制
错误处理机制是指：当 AI 工作流出错时，你设计的预防、检验、兜底、反馈环节。可以是"出错前的预设检验"（输入校验、边界约束）、"出错时的人工兜底路径"（异常转人工、回退默认值），也可以是"出错后的沉淀反哺"（错误案例库、Prompt 反哺训练）。
越完整的错误处理机制，意味着 AI 资产越能稳定持续运行。
